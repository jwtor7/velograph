# Synthetic fixtures

Everything in this directory is **invented**: values, dates (fictional year 2031), source
strings (`Synth Watch X1`), and routes. Route coordinates are deterministic random walks
inside an open-ocean bounding box near Point Nemo (the oceanic pole of inaccessibility),
so no fixture can trace a real person's ride or home.

Files under `rides/` are generated by `pnpm fixtures:generate`
(`scripts/generate-fixtures.mjs`) with a fixed seed and are committed so tests and CI run
without a generation step. Regenerate only via the script; never hand-edit values, and
never copy anything from a real export into this tree.

Files under `import-hardening/` are small, manually authored malformed and edge-case
inputs. Every value and route is invented and remains inside the same synthetic
open-ocean box. ZIP fixtures are never committed — tests build them in memory from
synthetic strings or files.

This is the **only** location where `.csv`/`.gpx` files are committable (see `.gitignore`
and `scripts/privacy-scan.mjs`, which additionally enforces the coordinate bounding box).
